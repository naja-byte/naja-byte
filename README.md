## `03` // CURRENT RESEARCH

### Oral Microbiome Characterization in COVID-19

Characterization of oral microbial communities using 16S rRNA gene sequencing and computational analysis of NGS data.

The project focuses on microbial community composition and diversity, applying bioinformatics workflows to process sequencing data and generate ecological and statistical summaries. Alpha diversity is used to investigate within-sample diversity, while beta diversity supports the assessment of differences in community composition between samples.

The analytical workflow integrates sequence processing, taxonomic assignment, diversity analysis, and multivariate statistical approaches to explore microbial community patterns in a clinical research setting.

`Workflow:` Sequencing Data → Quality Processing → ASV Inference → Taxonomic Assignment → Diversity Analysis → Statistical Interpretation

`Core tools:` DADA2 · QIIME 2 · VSEARCH · SILVA · BaseSpace CLI · R · Python
